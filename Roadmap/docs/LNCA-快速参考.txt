┌────────┬──────────────────────────────────────────────────────────────────┐
│ 0x00   │ ✅ 成功                                                          │
│ 0x66   │ ❌ 设备索引越界（检查 device.Index）                            │
│ 0x67   │ ❌ 句柄无效（设备未连接或已断开）                                │
│ 0x99   │ ❌ 擦除失败（可能需要 SO PIN 校验）                              │
│ 0x9000 │ ✅ APDU 命令成功（ISO 7816 标准状态字）                          │
│ 0x63Cx │ ⚠️  PIN 验证失败，剩余 x 次重试机会                             │
└────────┴──────────────────────────────────────────────────────────────────┘

用户代码 (LncaProvider.ResetDevice)
    │
    ├─> HSConnectDev(devIndex, &hDev)
    │     └─> 返回 0x00 = 成功，0x66 = 索引越界
    │
    ├─> [可选] HSVerifyUserPin(hDev, soPin, len)
    │     └─> 返回 0x00 = 验证成功，其他 = 失败
    │
    ├─> HSErase(hDev) ⭐⭐⭐ 核心操作
    │     │
    │     ├─> HS_Erase (HD_SortDev.dll)
    │     │     │
    │     │     ├─> HD_IC_RESET        (卡片复位，获取 ATR)
    │     │     ├─> HD_ClearDir        (清除目录结构)
    │     │     │     ├─> 发送 APDU 命令
    │     │     │     ├─> 检查 SW = 0x9000
    │     │     │     └─> Clear_DF (清除 DF 文件)
    │     │     ├─> HD_SPWD            (重置管理员密码)
    │     │     └─> 返回 0x00 = 全部成功
    │     │
    │     └─> 返回 0x00 = 成功，0x99 = 失败
    │
    └─> HSDisconnectDev(hDev)
          └─> 释放句柄，返回 0x00

ResetDevice 返回 false？

  1️⃣  检查 HD_HardAPI.dll 是否存在
     → 路径: SDK根目录/HD_HardAPI.dll
     → 不存在 → 下载完整 LNCA SDK

  2️⃣  检查设备索引
     → 调用 EnumerateDevices() 确认设备数量
     → 索引从 0 开始

  3️⃣  检查 SO PIN
     → 尝试 "", "111111", "123456"
     → 联系厂商确认默认值

  4️⃣  查看详细错误
     → 在 ResetViaHardApi 中添加日志
     → 记录每个函数的返回值

  5️⃣  验证 DLL 位数
     → 确保 HD_HardAPI.dll 是 32 位
     → 确保程序也是 32 位或启用 32 位支持

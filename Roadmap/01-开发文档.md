### 1.2 分层说明

#### 1.2.1 表示层（Presentation Layer）
- **USBKey.Manager**：WinForms桌面应用
- 职责：UI渲染、用户交互、调用业务逻辑
- 组件：MainForm、SettingsForm、LicenseActivateForm、Dialogs

#### 1.2.2 业务逻辑层（Business Logic Layer）
- **USBKey.Core**：核心库
- 职责：配置管理、授权校验、设备管理、证书操作
- 模块：Configuration、Licensing、UsbKey、Crypto、Native、Service

#### 1.2.3 数据访问层（Data Access Layer）
- 配置文件：config.json（JSON序列化）
- 授权文件：license.key（JSON序列化）
- 日志文件：logs/app_yyyyMMdd.log（文本追加）

#### 1.2.4 基础设施层（Infrastructure Layer）
- 厂商DLL：通过P/Invoke + GetProcAddress调用
- 系统API：WMI、CryptoAPI、X509Store
- 网络服务：联网取时、可选REST API

### 1.3 关键设计模式

#### 1.3.1 策略模式（Strategy Pattern）
- **接口**：`IKeyProvider`
- **实现**：`LncaProvider`（LNCA/JIT_USBKEY_HD + HD_HardAPI）、`HengBaoProvider`（恒宝/CMBCp，标准 PKCS#11）、`EPass3003Provider`（EnterSafe/ePass3003，PKCS#11）、`MockKeyProvider`（模拟）
- **管理**：`KeyManager` 根据 `config.platform` 选择 Provider
- **优势**：支持多厂商扩展，添加新厂商只需实现接口

#### 1.3.2 单例模式（Singleton Pattern）
- **应用**：`Program.Ctx`（全局应用上下文）
- **实现**：静态属性 + 启动时初始化
- **原因**：全局共享配置、KeyManager、授权状态

#### 1.3.3 观察者模式（Observer Pattern）
- **事件**：`AppContext.OnStateChanged`
- **订阅者**：MainForm（刷新UI）
- **发布者**：登录/登出、设备变化
- **优势**：UI与业务逻辑解耦

#### 1.3.4 工厂模式（Factory Pattern）
- **工厂**：`KeyManager.Register(provider)`
- **产品**：各厂商的 `IKeyProvider` 实现
- **优势**：统一创建与管理

### 2.2 授权体系（Licensing）

#### 2.2.1 机器码生成

**算法**：
```
machineCode = SHA256(CPUID + "|" + HDDSerial + "|" + MotherboardUUID)
格式化：前32字符分4段，每段8字符，用"-"连接
示例：12345678-90ABCDEF-12345678-90ABCDEF
```

**实现**：
```csharp
public static class MachineCode
{
    public static string Get()
    {
        var cpu = WmiQuery("Win32_Processor", "ProcessorId");
        var disk = WmiQuery("Win32_DiskDrive", "SerialNumber");
        var mb = WmiQuery("Win32_BaseBoard", "SerialNumber");
        var uuid = WmiQuery("Win32_ComputerSystemProduct", "UUID");
        
        var raw = $"CPU={cpu};DISK={disk};MB={mb};UUID={uuid}";
        var hash = SHA256.HashData(Encoding.UTF8.GetBytes(raw));
        return FormatMachineCode(hash);
    }
}
```

**特性**：
- 硬件不变则机器码稳定
- 更换主板/硬盘会导致机器码变化
- 虚拟机环境可能获取到虚拟硬件ID

#### 2.2.2 授权签名与验证

**签名算法**：RSA-PKCS1-SHA256

**签名内容**：
```
payload = MachineCode + "|" + Expiry(yyyyMMdd) + "|" + Platforms(逗号分隔)
signature = RSA.Sign(payload, privateKey, SHA256, PKCS1)
```

**验证流程**：
```csharp
public static LicenseCheckResult Check(
    string licensePath, 
    string currentMachineCode, 
    IEnumerable<string> requiredPlatforms, 
    DateTime? nowUtc = null)
{
    // 1. 读取license.key
    var doc = JsonSerializer.Deserialize<LicenseDocument>(File.ReadAllText(licensePath));
    
    // 2. 验证签名
    if (!VerifySignature(doc)) 
        return new LicenseCheckResult { Status = LicenseStatus.SignatureInvalid };
    
    // 3. 验证机器码
    if (doc.MachineCode != currentMachineCode)
        return new LicenseCheckResult { Status = LicenseStatus.MachineMismatch };
    
    // 4. 验证到期时间（使用网络时间）
    var now = nowUtc ?? NetworkTime.TryGetUtcNow(out var netTime) ? netTime : DateTime.UtcNow;
    if (DateTime.Parse(doc.Expiry) < now.Date)
        return new LicenseCheckResult { Status = LicenseStatus.Expired };
    
    // 5. 验证平台授权
    if (!doc.Platforms.Overlaps(requiredPlatforms))
        return new LicenseCheckResult { Status = LicenseStatus.PlatformMismatch };
    
    return new LicenseCheckResult { Status = LicenseStatus.Valid };
}
```

**联网取时**：
```csharp
public static class NetworkTime
{
    public static bool TryGetUtcNow(out DateTime utcNow)
    {
        // 尝试多个时间源
        string[] sources = {
            "https://www.baidu.com",
            "https://www.microsoft.com"
        };
        
        foreach (var url in sources) {
            using var resp = httpClient.Send(new HttpRequestMessage(HttpMethod.Head, url));
            if (resp.Headers.Date.HasValue) {
                utcNow = resp.Headers.Date.Value.UtcDateTime;
                return true;
            }
        }
        utcNow = DateTime.UtcNow;
        return false;
    }
}
```

### 2.3 设备与证书管理（UsbKey）

#### 2.3.1 接口抽象（IKeyProvider）

**设计原则**：
- 不提供破解接口（导出私钥、无凭据解锁）
- 所有操作需先 `Login(device, pin)`
- 异常统一抛出带描述的 `InvalidOperationException` 或 `NotSupportedException`

**关键方法**：
```csharp

    void ExportCertificate(UsbKeyDevice device, KeyContainer container, string outputPath);
    void DeleteContainer(UsbKeyDevice device, KeyContainer container);
    void RegisterToCsp(KeyContainer container);
    void UnregisterFromCsp(KeyContainer container);
    
    // 密码与解锁
```

#### 2.3.2 Mock实现（MockKeyProvider）

**用途**：无实物设备时的演示与测试

**特性**：
- 生成自签名X509证书（使用 `CertificateRequest`）
- 模拟2个证书容器
- PIN验证：`123456`，PUK：`12345678`
- 支持所有接口操作（导入/导出/删除/注册/解锁/重置）

**证书生成**：
```csharp
private static KeyContainer CreateCert(string cn, string issuerCn, int bits)
{
    using var rsa = RSA.Create(bits);
    var req = new CertificateRequest($"CN={cn}", rsa, HashAlgorithmName.SHA256, RSASignaturePadding.Pkcs1);
    req.CertificateExtensions.Add(new X509KeyUsageExtension(
        X509KeyUsageFlags.DataEncipherment | X509KeyUsageFlags.DigitalSignature, false));
    
    var now = DateTime.Now;
    using var cert = req.CreateSelfSigned(now.AddDays(-30), now.AddYears(3));
    
    return new KeyContainer {
        Name = cn,
        Subject = cert.Subject,
        NotBefore = cert.NotBefore,
        NotAfter = cert.NotAfter,
        SerialNumber = cert.SerialNumber,
        Thumbprint = cert.Thumbprint,
        Algorithm = $"RSA {bits}/SHA256",
        CertRaw = cert.Export(X509ContentType.Cert)
    };
}
```

```csharp
[UnmanagedFunctionPointer(CallingConvention.StdCall)]
private delegate int LoginFunc(IntPtr handle, [MarshalAs(UnmanagedType.LPStr)] string pin);

private T? TryBind<T>(ushort ordinal) where T : Delegate
{
    if (_module == null) return null;
    return _module.GetDelegateByOrdinal<T>(ordinal);
}

// 调用（示例，待实物确认签名）
public void Login(UsbKeyDevice device, string pin)
```

**序号导出解析**：
```csharp
// 序号形式："#" + ordinal
private static IntPtr GetProcAddressOrdinal(IntPtr hModule, ushort ordinal)
{
    return GetProcAddress(hModule, "#" + ordinal);
}

public T? GetDelegateByOrdinal<T>(ushort ordinal) where T : Delegate
{
    var addr = GetProcAddressOrdinal(Handle, ordinal);
    if (addr == IntPtr.Zero) return null;
    return Marshal.GetDelegateForFunctionPointer<T>(addr);
}
```

**使用示例**：
```csharp

if (module == null) throw new FileNotFoundException("DLL未找到");

if (func != null) {
    int ret = func(param1, param2);
}
```

```csharp
private void Handle(HttpListenerContext ctx)
{
    var seg = ctx.Request.Url!.AbsolutePath.Trim('/').ToLowerInvariant();
    var resp = seg switch
    {
        "devices" => new ApiResult { Success = true, Data = _keys.EnumerateAll() },
        "login" => HandleLogin(ctx.Request), // 新增
        _ => new ApiResult { Success = false, Message = "未知接口" },
    };

}

private object HandleLogin(HttpListenerRequest req)
{
    // 解析POST body（JSON）
    using var reader = new StreamReader(req.InputStream);
    var json = reader.ReadToEnd();
    var data = JsonSerializer.Deserialize<Dictionary<string, string>>(json);
    
    var platform = data["platform"];
    var serial = data["serial"];
    var pin = data["pin"];
    
    var prov = _keys.GetProvider(platform);
    var dev = prov?.Open(int.Parse(serial));
    prov?.Login(dev, pin);
    
    return new { Success = true, Message = "登录成功" };
}
```

1. **及时释放**：Provider使用完毕后Dispose
2. **图像资源**：托盘图标使用系统图标
3. **事件订阅**：窗体关闭时取消订阅

## 10. 安全加固

### 10.1 代码混淆

**工具**：ConfuserEx、Obfuscar

**配置示例**（Obfuscar）：
```xml
<Obfuscator>
  <Var name="InPath" value=".\bin\Release" />
  <Var name="OutPath" value=".\bin\Obfuscated" />
  
  <Module file="$(InPath)\USBKey.Core.dll">
    <SkipType name="USBKey.Core.UsbKey.IKeyProvider" />
  </Module>
  
  <Module file="$(InPath)\USBKey.Manager.exe" />
</Obfuscator>
```

### 10.2 授权密钥保护

**生产环境**：
1. 重新生成RSA密钥对（工具：tools/genkeys）
2. 替换 `LicenseVerifier` 中的公钥
3. 替换 `LicenseIssuer` 中的私钥
4. 私钥仅授权终端持有，不得外传

**密钥生成**：
```powershell
cd c:\USBKey\tools\genkeys
dotnet run

# 输出：
# === PUBLIC (SubjectPublicKeyInfo base64) ===
# MIIBIjAN...（复制到LicenseVerifier）
# 
# === PRIVATE (PKCS8 base64) ===
# MIIEvAIB...（复制到LicenseIssuer）
```

### 10.3 敏感数据保护

**配置文件**：
- `config.json`：明文（无敏感数据）
- `license.key`：签名保护（不可伪造）

**内存保护**：
- PIN输入：`UseSystemPasswordChar = true`
- 登录后：不在内存中明文存储PIN

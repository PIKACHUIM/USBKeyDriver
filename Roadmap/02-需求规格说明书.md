# USB Key 管理端系统 - 需求规格说明书

**项目名称**：USB Key 管理端系统  
**文档版本**：v1.0  
**编制日期**：2026-08-23  
**项目状态**：已交付

---

## 1. 项目概述

### 1.1 项目背景

企业需要一套统一的 USB Key（智能卡）管理系统，用于管理员工的数字证书、设备密码、设备解锁等操作。现有厂商提供的管理工具功能受限、界面陈旧、不支持多厂商统一管理。

### 1.2 项目目标

开发一套企业级 USB Key 管理端软件，实现：
- 统一的设备与证书管理界面
- 支持多厂商 USB Key（当前重点：LNCA）
- 双模式运行：用户模式（普通员工）+ 管理模式（IT管理员）
- 基于授权的权限管控（管理模式需机器码绑定授权）
- 不提供任何破解能力（导出私钥、无凭据解锁等）

### 1.3 项目范围

**包含**：
- 管理端桌面应用（WinForms，720x480）
- 授权生成终端（仅授权管理员使用）
- 核心库（配置、授权、DLL对接、证书操作）
- 完整文档与部署指南

**不包含**：
- Web管理后台
- 移动端APP
- 云端证书同步服务（预留接口）

## 2. 功能需求

### 2.1 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| **普通用户** | 企业员工，使用 USB Key 进行日常工作 | 查看证书、登录/登出、注册证书到系统 |
| **IT管理员** | 企业IT部门，负责设备管理与证书部署 | 导入证书、修改密码、解锁设备、重置设备、配置用户权限 |
| **授权管理员** | 软件授权方，负责生成授权文件 | 生成license.key |

### 2.2 运行模式

#### 2.2.1 用户模式（usermode=true）

**特点**：
- 不需要授权文件（license.key）
- 功能受限（不能导入证书、修改密码、解锁、重置）
- 适用于普通员工日常使用

**核心功能**：
- 查看 USB Key 设备信息
- PIN 登录/登出
- 查看证书列表与详情
- 导出证书（仅公钥）
- 注册/注销证书到系统 CSP

#### 2.2.2 管理模式（usermode=false）

**特点**：
- 需要有效的授权文件（绑定机器码）
- 启动时联网获取时间（防本地时钟篡改）
- 完整的管理功能
- 可配置用户客户端权限

**核心功能**：
- 用户模式的所有功能
- 导入 PFX 证书到 USB Key
- 修改设备 PIN
- 解锁设备（PUK/Admin Key/挑战码）
- 重置设备（初始化、清除所有证书）
- 系统设置（配置用户权限、查看授权状态）

### 2.3 核心功能模块

#### 2.3.1 设备管理

**FR-DM-001：设备枚举**
- 系统应能自动检测已插入的 USB Key 设备
- 支持多厂商设备（通过 VID/PID 白名单）
- 显示设备名称、序列号、型号、VID/PID

**FR-DM-002：设备选择**
- 用户可从下拉列表选择要操作的设备
- 同时支持多台设备插入（逐个操作）

**FR-DM-003：设备详情**
- 显示序列号、固件版本、容量、VID/PID
- 显示当前登录状态

**FR-DM-004：USB热插拔**
- 设备插入/拔出时自动刷新列表
- 托盘气泡提示设备变化

#### 2.3.2 登录与会话管理

**FR-LS-001：PIN登录**
- 用户输入 PIN 进行设备解锁
- 登录成功后进入"已登录"状态
- 登录失败提示错误次数（防暴力破解）

**FR-LS-002：登出**
- 用户可主动登出（锁定设备）
- 关闭软件时自动登出

**FR-LS-003：会话超时**
- 登录后默认15分钟超时（可配置）
- 超时后自动登出并提示重新登录

#### 2.3.3 证书管理

**FR-CM-001：证书列表**
- 登录后显示设备上的所有证书
- 列表列：证书名称、有效期、加密算法
- 支持选择查看详情

**FR-CM-002：证书详情**
- 显示主题（Subject DN）
- 显示签发者（Issuer DN）
- 显示有效期（起止日期）
- 显示密钥用途（Key Usage）
- 显示扩展用途（Extended Key Usage）
- 显示算法（RSA 2048、SHA256 等）
- 显示容器 UUID
- 显示是否已注册到系统 CSP

**FR-CM-003：查看证书**
- 双击证书或点击"查看"按钮打开系统证书查看器
- 展示完整的证书链与详情

**FR-CM-004：导入证书（管理模式）**
- 支持本地 PFX 文件导入
- 输入 PFX 密码
- 导入成功后自动刷新列表

**FR-CM-005：导出证书**
- 导出为 .cer 或 .crt 文件
- 仅导出公钥证书，不含私钥
- 支持另存为指定路径

**FR-CM-006：删除证书**
- 从 USB Key 删除选中的证书/容器
- 二次确认（防误删）
- 若已注册到 CSP，自动注销

**FR-CM-007：注册/注销证书**
- 注册：将证书添加到系统"个人"证书库（当前用户）
- 注销：从系统证书库移除
- 切换状态时自动刷新详情

**FR-CM-008：云端导入（预留）**
- 功能状态：hidden（当前不可见）
- 预留接口供后续对接云端证书服务

#### 2.3.4 密码与解锁

**FR-PW-001：修改密码（管理模式）**
- 输入当前 PIN
- 输入新 PIN（至少6位）
- 二次确认新 PIN
- 修改成功后提示

**FR-PW-002：解锁设备（管理模式）**
- 支持三种解锁方式：
  1. **PUK解锁**：输入 PUK + 新 PIN
  2. **Admin Key解锁**：输入 Admin Key + 新 PIN
  3. **挑战码解锁**：管理员生成挑战码，用户提供响应 + 新 PIN
- 解锁成功后设备恢复可用状态

**FR-PW-003：重置设备（管理模式）**
- 初始化设备（清除所有证书与密钥）
- 设置新的 PIN（必填，至少6位）
- 可选设置 PUK（留空则随机生成）
- 可选设置 Admin Key（留空则随机生成）
- 二次确认（防止误操作）
- 重置后自动登录

#### 2.3.5 系统设置

**FR-ST-001：用户设置页签**
- 允许删除证书（checkbox，默认否）
- 允许修改密码（checkbox，默认否）
- 登录有效期（分钟，默认15）
- 云端证书导入地址（文本框，空表示未配置）
- 开机自启动（checkbox，默认是）
- 证书自动注册到系统（checkbox，默认是）
- 软件信息展示（名称、版权、构建日期、支持平台）

**FR-ST-002：管理设置页签（仅管理模式）**
- 配置用户权限（生成用户客户端 config）：
  - 允许用户删除证书（enabled/disabled）
  - 允许用户云端导入证书（enabled/hidden）
  - 允许用户解锁设备（enabled/disabled）
  - 允许用户导出证书（enabled/disabled）
- 授权信息展示：
  - 机器码（可复制）
  - 授权状态（已授权/未授权）
  - 授权有效期
  - 更新授权按钮（提示手动替换 license.key）

**FR-ST-003：保存设置**
- 点击"保存"按钮后写入 config.json
- 保存成功提示
- 部分配置需重启生效

#### 2.3.6 托盘功能

**FR-TR-001：托盘图标**
- 最小化时隐藏主窗口，显示托盘图标
- 托盘图标显示软件名称

**FR-TR-002：托盘菜单**
- 显示主界面（双击图标或右键菜单）
- 查看/弹出 USB Key（列出已插入设备）
- 退出（关闭程序）

**FR-TR-003：气泡提示**
- 首次最小化时提示"程序已最小化到托盘"
- USB 设备插入/拔出时提示（可选）

#### 2.3.7 授权管理

**FR-LC-001：授权激活（管理模式启动）**
- 首次启动或授权无效时弹出激活窗口
- 显示本机机器码（格式：XXXX-XXXX-XXXX-XXXX）
- 提供"复制机器码"按钮
- 输入授权内容（license JSON）
- 点击"保存并验证授权"
- 验证通过后保存到 config/license.key 并继续运行
- 验证失败提示错误原因

**FR-LC-002：授权校验**
- 启动时读取 license.key
- 验证签名（RSA公钥验签）
- 验证机器码绑定
- 验证到期时间（联网获取网络时间）
- 验证平台授权（授权平台需包含 config.platform）
- 校验失败则拒绝启动并提示

**FR-LC-003：授权生成终端**
- 独立的 WinForms 应用
- 输入目标机器码（文本框）
- 勾选授权平台（CheckedListBox，支持多选）
- 选择授权有效期（DateTimePicker，默认1年）
- 点击"生成授权"按钮
- 输出授权 JSON（TextBox，只读）
- 提供"复制到剪贴板"和"保存为 license.key"按钮

## 3. 非功能需求

### 3.1 性能需求

**NFR-PF-001：启动速度**
- 冷启动时间 < 3秒（不含授权联网取时）
- 授权联网取时超时：8秒

**NFR-PF-002：响应速度**
- UI操作响应 < 200ms
- 设备枚举 < 1秒
- 证书列表加载 < 2秒

**NFR-PF-003：资源占用**
- 内存占用 < 100MB（空闲时）
- CPU占用 < 5%（空闲时）

### 3.2 兼容性需求

**NFR-CP-001：操作系统**
- Windows 10 x64（1809及以上）
- Windows 11 x64
- 需要 .NET 8 Desktop Runtime

**NFR-CP-002：硬件环境**
- CPU：x64架构，1GHz及以上
- 内存：4GB及以上
- 磁盘：50MB可用空间

**NFR-CP-003：厂商支持**
- 当前重点：LNCA平台（需实物设备 + IDA逆向对接）
- 可扩展：通过实现 IKeyProvider 接口支持新厂商
- 内置：Mock平台（演示与测试）

### 3.3 安全需求

**NFR-SC-001：授权安全**
- 采用 RSA-2048 签名算法
- 公钥内嵌在软件中，私钥由授权管理员单独持有
- 授权绑定机器码（CPUID+硬盘序列号+主板UUID的SHA256）
- 联网获取时间防本地时钟回拨

**NFR-SC-002：不提供破解能力**
- 不导出私钥（证书导出仅含公钥）
- 不提供无凭据解锁/改密（所有操作必须先认证）
- 接口层设计排除破解型方法

**NFR-SC-003：敏感操作保护**
- 导入证书、重置设备、解锁设备：管理模式下再次校验授权
- 删除证书：二次确认
- 重置设备：二次确认 + 警告提示

**NFR-SC-004：会话安全**
- 登录会话超时保护（默认15分钟）
- 超时后自动登出
- 关闭软件自动登出

### 3.4 可用性需求

**NFR-US-001：界面设计**
- 主窗体尺寸：720x480（固定，不可调整大小）
- 字体：Microsoft YaHei UI，9pt
- 布局：左侧操作按钮 + 详情，右侧证书列表
- 支持键盘操作（Tab切换、Enter确认）

**NFR-US-002：错误提示**
- 所有操作失败时弹出明确的错误提示
- 错误信息包含具体原因（如"PIN错误"、"授权过期"）

**NFR-US-003：操作反馈**
- 长时间操作（>1秒）显示进度提示
- 操作成功时弹出确认消息
- 关键操作（删除、重置）需用户确认

### 3.5 可维护性需求

**NFR-MT-001：日志记录**
- 启动/退出日志
- 授权校验日志
- 异常日志（含堆栈）
- 日志文件位置：运行目录/logs/app_yyyyMMdd.log

**NFR-MT-002：配置外部化**
- 所有功能开关通过 config.json 配置
- 配置文件位置：运行目录/config/config.json
- 配置文件支持热重载（部分配置需重启）

**NFR-MT-003：模块化设计**
- 核心库独立（USBKey.Core.dll）
- UI与业务逻辑分离
- 厂商接口抽象（IKeyProvider）

## 4. 数据需求

### 4.1 配置文件（config.json）

**结构**：
```json
{
  "usermode": false,
  "platform": ["lnca", "mock"],
  "keyslist": {
    "lnca": [{"name":"LNCA安全USBKey", "vid":"16A0", "pid":"0D00"}]
  },
  "features": {
    "importcert": "enabled",
    "viewcert": "enabled",
    "exportcert": "enabled",
    "delcert": "disabled",
    "regcert": "enabled",
    "changepin": "disabled",
    "unlock": "enabled",
    "reset": "enabled",
    "cloudimport": "hidden"
  },
  "settings": {
    "allowDeleteCert": false,
    "allowChangePin": false,
    "loginTimeoutMinutes": 15,
    "cloudEndpoint": "",
    "autoStart": true,
    "autoRegisterCert": true
  },
  "api": {
    "enabled": false,
    "port": 18443,
    "token": ""
  }
}
```

**字段说明**：
- `usermode`：运行模式（true=用户模式，false=管理模式）
- `platform`：启用的平台列表
- `keyslist`：各平台的 VID/PID 白名单
- `features`：功能按钮状态（enabled/hidden/disabled）
- `settings`：用户偏好设置
- `api`：可选REST API配置（管理模式）

### 4.2 授权文件（license.key）

**结构**：
```json
{
  "LicenseId": "A1B2C3D4E5F67890",
  "MachineCode": "12345678-90ABCDEF-12345678-90ABCDEF",
  "Expiry": "2027-08-23",
  "Platforms": ["lnca", "mock"],
  "IssuedAt": "2026-08-23T10:00:00Z",
  "Signature": "urlsafe_base64_signature"
}
```

**字段说明**：
- `LicenseId`：授权唯一标识
- `MachineCode`：目标机器码
- `Expiry`：授权到期日期（yyyy-MM-dd）
- `Platforms`：授权支持的平台列表
- `IssuedAt`：签发时间
- `Signature`：RSA签名（对 "MachineCode|Expiry|Platforms" 规范化串的签名）

### 4.3 数据模型

**设备模型（UsbKeyDevice）**：
- Platform（平台名）
- VendorName（厂商名）
- Model（型号）
- SerialNumber（序列号）
- Handle（句柄/索引）
- Vid/Pid（USB设备ID）
- FirmwareVersion（固件版本）
- CapacityKb（容量）
- IsLoggedIn（登录状态）

**证书模型（KeyContainer）**：
- Name（证书名称/CN）
- ContainerName（容器名）
- ContainerUuid（容器UUID）
- Algorithm（算法描述）
- Subject（主题DN）
- Issuer（签发者DN）
- NotBefore/NotAfter（有效期）
- KeyUsage（密钥用途）
- ExtendedKeyUsage（扩展用途）
- SerialNumber（证书序列号）
- Thumbprint（指纹）
- IsRegisteredInCsp（是否已注册到CSP）
- CertRaw（证书字节）

## 5. 接口需求

### 5.1 厂商DLL接口（IKeyProvider）

**抽象接口**：
```csharp
public interface IKeyProvider : IDisposable
{
    string PlatformName { get; }
    bool IsAvailable { get; }
    void Initialize();
    IReadOnlyList<UsbKeyDevice> Enumerate();
    UsbKeyDevice Open(int handleOrSerial);
    void Login(UsbKeyDevice device, string pin);
    void Logout(UsbKeyDevice device);
    UsbKeyDevice GetDetail(UsbKeyDevice device);
    IReadOnlyList<KeyContainer> ListContainers(UsbKeyDevice device);
    void ImportPfx(UsbKeyDevice device, string pfxPath, string pfxPassword);
    void ExportCertificate(UsbKeyDevice device, KeyContainer container, string outputPath);
    void ViewCertificate(KeyContainer container);
    void DeleteContainer(UsbKeyDevice device, KeyContainer container);
    void RegisterToCsp(KeyContainer container);
    void UnregisterFromCsp(KeyContainer container);
    void ChangePin(UsbKeyDevice device, string oldPin, string newPin);
    void Unlock(UsbKeyDevice device, UnlockMethod method, string credential, string newPin);
    string GenerateChallenge(UsbKeyDevice device);
    void UnlockByChallenge(UsbKeyDevice device, string challenge, string response, string newPin);
    void ResetDevice(UsbKeyDevice device, string newPin, string? puk, string? adminKey);
}
```

**实现要求**：
- 每个厂商实现自己的 Provider（如 LncaProvider、MockKeyProvider）
- 通过 KeyManager 统一管理
- 异常处理：所有方法失败时抛出带描述的异常

### 5.2 REST API接口（可选，管理模式）

**端点**：
- `GET /devices`：枚举所有设备
- `GET /device?platform=xxx&serial=xxx`：获取设备详情

**认证**：
- Header: `Authorization: Bearer {token}`
- token 配置在 config.json 的 api.token

**响应格式**：
```json
{
  "Success": true,
  "Message": "",
  "Data": {...}
}
```

## 6. 约束与限制

### 6.1 技术约束

- 必须使用 .NET 8（C# 12）
- UI框架：Windows Forms
- 不使用第三方 NuGet 包（除 System.Management）
- 目标平台：net8.0-windows

### 6.2 业务约束

- 不得提供导出私钥功能
- 不得提供无凭据解锁/改密功能
- 授权必须绑定机器码（不可跨机器使用）
- 管理模式必须联网校验时间

### 6.3 部署约束

- 绿色软件（无需安装，复制即用）
- 依赖 .NET 8 Desktop Runtime（需预装或随软件分发）
- 授权终端不得与管理端一起分发（仅授权管理员持有）

## 7. 验收标准

### 7.1 功能验收

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC-01 | 用户模式启动 | 无需授权，可正常启动并枚举Mock设备 |
| AC-02 | 管理模式启动 | 需有效授权，启动时联网取时并校验 |
| AC-03 | 设备枚举 | 可检测已插入的USB Key（Mock/LNCA） |
| AC-04 | PIN登录 | 输入正确PIN可登录，错误PIN提示失败 |
| AC-05 | 证书列表 | 登录后显示所有证书，双击可查看详情 |
| AC-06 | 导入证书 | 管理模式可导入PFX，导入成功后列表刷新 |
| AC-07 | 导出证书 | 可导出为.cer文件，仅含公钥 |
| AC-08 | 删除证书 | 二次确认后可删除，列表刷新 |
| AC-09 | 注册证书 | 可注册/注销到系统CSP |
| AC-10 | 修改密码 | 管理模式可修改PIN |
| AC-11 | 解锁设备 | 管理模式可通过PUK/AdminKey/挑战码解锁 |
| AC-12 | 重置设备 | 管理模式可重置设备并清除所有证书 |
| AC-13 | 系统设置 | 可修改配置并保存到config.json |
| AC-14 | 托盘功能 | 最小化到托盘，双击恢复，右键菜单可退出 |
| AC-15 | USB热插拔 | 插入/拔出设备时自动刷新列表 |
| AC-16 | 授权生成 | 授权终端可生成有效的license.key |

### 7.2 性能验收

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AP-01 | 启动速度 | 冷启动 < 3秒 |
| AP-02 | 设备枚举 | < 1秒 |
| AP-03 | 证书加载 | < 2秒 |

### 7.3 安全验收

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AS-01 | 授权校验 | 无效授权无法启动管理模式 |
| AS-02 | 机器码绑定 | 授权在其他机器无法使用 |
| AS-03 | 联网取时 | 管理模式启动必须获取网络时间 |
| AS-04 | 不导出私钥 | 证书导出文件不含私钥 |
| AS-05 | 无破解接口 | 代码审查确认无无凭据解锁/改密 |
